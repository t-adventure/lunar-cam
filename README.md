# Lunar Cam — 月面撮影シミュレータ

iPhone / iPad のブラウザで動く、単一ファイル(`index.html`)のWebアプリです。
カメラで撮影した人工衛星・月面ローバーなどの模型を最前面に残し、それ以外を **月面・星空・地球** のリアルタイム描画に置き換えます。端末の姿勢や位置の変化に合わせて、背景の見え方も変わります。

**公開URL:** https://t-adventure.github.io/lunar-cam/

## 使い方

1. Safari などで上のURLを開き、画面中央の「📷 カメラを起動して始める」を押します。カメラと、動きセンサー(iPhone/iPad)を許可します。
2. 上部のスイッチで、「📦 ものを撮る」か「🧍 人物を撮る」を選びます(始める前でも、あとからでも切り替えられます)。
3. ものモードでは、画面に映ったものを**タップ**して対象を指定します。人物モードは自動で検出します。
4. 対象が決まると、「🌕 背景合成」が自動でONになり、対象が最前面に残って、背景が月面に置き換わります。初期状態はOFFで、カメラの映像がそのまま映ります。
5. **ジャイロは、始めると自動でONになります**。端末を動かすと、月面・星空・地球も一緒に動きます(センサーのない端末では、自動で非表示になります)。
6. 構図が決まったら、画面下中央の大きな丸い「📸 撮影(写真)」ボタンで撮影します。「🎥 動画撮影」で動画も撮れます。撮影後の画面で、「保存 / 共有」を押すと保存できます。
7. カメラを止めるときは、画面上部の「⏹ カメラ停止」を押します。

## 主な機能

| 機能 | 内容 |
|---|---|
| 人物モード | 映っている人物(1人でも複数人でも)を、タップなしで自動で切り抜いて最前面に残します。PCの前に座った上半身の撮影を想定しています。 |
| タップで対象を指定・追跡 | タップした点から、ものの色の特徴を学習して追跡します。ものを最前面、それ以外を背景として描画します。 |
| ジャイロ連動 | 端末の3軸の姿勢(傾きを含む)を使い、星・地球・太陽・月面を実際の向きで描画します。 |
| 月面 | クレーター・岩・砂のでこぼこを持つ起伏データから生成します。低い太陽光による陰影と、くっきりした影が出ます。 |
| 距離に連動する見え方 | ものの映る大きさと位置の変化から端末の動きを推定し、月面が近づいたり遠ざかったりして見えます。 |
| 星空・地球 | 星空と天の川、満ち欠けのある地球を、太陽の位置と連動して描画します。 |
| ものとの合成 | ものが地面に落とす影、太陽側の明るさ、地球照(青い反射光)を加えます。 |
| 保存 | 描画した画面を PNG で保存、または動画で録画します。 |

## 操作

- **ドラッグ**: 視点を動かします(ジャイロ中は方位をずらします)。
- **ピンチ(2本指)**: 月面からの高度を変えます。広げると近づき、縮めると遠ざかります。
- **視点のボタン**: ⬇ 地表 / ➖ 水平線 / 🌍 地球 / ✨ 星空
- **⌖ 正面**: ジャイロ中に、いま向いている方向を正面にします。
- **✖ 対象を解除**(ものモードで追跡中のみ表示): 追跡中のものを解除します。ものの別の部分をタップすると、その部分も対象に追加されます。

## ものモードと人物モード

画面上部の切り替えスイッチ「📦 ものを撮る / 🧍 人物を撮る」で切り替えます。選ばれているほうが青く光ります。その下の状態表示(カメラ、背景合成、ジャイロ、対象または人物)に、いまの状態が出ます。

- **ものモード**: 模型などを、タップで指定して追跡します。背面カメラが標準です。
- **人物モード**: AIモデルで、人物を自動で検出して切り抜きます。前面カメラが標準で、映像は鏡像で表示します。
  - 設定の「上半身の下端」で、画面の下側を切る位置を決めます。立って全身が映るときに、上半身だけを残せます。
  - 人物が消えて背景だけが残る場合は、「⇄ マスク反転」を押してください。
  - 初回だけ、モデルの読み込みに数秒かかります。

## 設定(⚙)

「⚙ 設定」を押すと、タブ(対象 / 光と影 / 宇宙 / 視点・カメラ)ごとに整理された設定が開きます。

- **背景除去**: タップ指定(標準)のほか、緑・青・黒・白のクロマキー、タップした色の指定、背景差分のモードがあります。
- **宇宙の見た目**: 太陽の方位・高度、地形の影、ものの影の長さ、ものの陰影、地球照、地球の大きさ、星の量、被写体のコントラスト。
- **月面との距離感**: カメラ高度、距離連動の強さ、移動の倍率、撮影距離。
- **カメラ・視点**: 画角、背景の画質、前面/背面カメラの切り替え。

動きが重いときは、「背景の画質」を下げてください。

## 動作環境

- **HTTPS で開く必要があります。** カメラとジャイロは、HTTPS でないと許可されません(`http://` の社内サーバーなどでは動きません)。
- iOS 14.5 以降の Safari を想定しています。Chrome・Edge などでも動く見込みですが、確認していません。
- LINE・Instagram などのアプリ内ブラウザでは、カメラが許可されないことがあります。Safari で開いてください。
- iOS では、初回に「モーションセンサー」の許可が必要です。

## うまく動かないとき

- **カメラが起動しない**: ブラウザのカメラ許可を確認してください。画面に、原因を示す赤いメッセージが出ます。
- **映像が映らない**: 他のアプリ(Zoomなど)がカメラを使っていないか確認してください。別のブラウザでも試してください。
- **ジャイロをONにできない(iPhone/iPad)**: 動きセンサーの許可を一度「拒否」すると、確認が再び出なくなります。Safariを完全に終了して開き直し、許可で「許可」を選んでください。それでも出ない場合は、設定 → Safari → 詳細 → Webサイトデータ で、このサイトのデータを削除してから、もう一度開いてください。
- **画面が拡大されて戻らない(iPhone)**: ページの拡大は、できないようにしてあります。すでに拡大された場合は、ページを再読み込みしてください。

## 制限事項

- 位置の推定は、ものの映る大きさと位置の変化を使っています。ARKit のような正確な位置追跡ではありません。
- ものと背景の色が近いと、うまく切り出せません。ものが画面の端にかからないようにしてください。
- 素早く動かすと、追跡が外れることがあります。外れたときは、もう一度ものをタップしてください。
- iOS のジャイロの方位は、相対値です。実際の北とは一致しません。
- 複数の端末は、互いに通信しません。設定や映像は、端末ごとに独立しています。

## 開発

- ビルドは不要です。`index.html` が本体で、人物モード用に `mediapipe/` を同梱しています(外部サービスには依存しません)。
- 月面・地球・星の画像は、起動時にコードで生成します。
- ローカルで試すときは、HTTPS で配信する必要があります(カメラ許可のため)。
- GitHub Pages で公開しています。`main` ブランチのルートが公開されます。`index.html` を更新してプッシュすると、1〜2分で反映されます。

`mediapipe/` には、Google の MediaPipe Tasks Vision(Apache License 2.0)と、Selfie Segmenter モデルを同梱しています。詳細は `mediapipe/NOTICE.md` と `mediapipe/LICENSE` を参照してください。

## 技術メモ

- 描画は Canvas 2D です。月面は、レイとの平面の交差で、1ピクセルずつ計算しています。
- 月面の起伏データ(高さと反射率)は、ミップマップにしてあります。拡大・縮小しても細部が出続けるように、16倍ごとの階層で自己相似に重ねます。
- 影は、起伏データの地平線テストで計算します(太陽が動くと再計算)。
- 人物モードは、MediaPipe の Selfie Segmenter で人物マスクを毎フレーム求め、時間方向に平滑化して使います。
- ものの追跡は、色のヒストグラムによる前景/背景の分類と、連結成分の選択で行います。
