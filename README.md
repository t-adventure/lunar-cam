# Lunar Cam — 月面撮影シミュレータ

iPhone / iPad のブラウザで動く、単一ファイル(`index.html`)のWebアプリです。
カメラで撮影した人工衛星・月面ローバーなどの模型を最前面に残し、それ以外を **月面・星空・地球** のリアルタイム描画に置き換えます。端末の姿勢や位置の変化に合わせて、背景の見え方も変わります。

**公開URL:** https://t-adventure.github.io/lunar-cam/

## 使い方

1. Safari で上のURLを開きます。
2. 「📷 撮影開始」を押して、カメラを許可します。
3. 画面に映った**ものをタップ**します。そのものが最前面に残り、背景が月面に置き換わります。
4. 「🧭 ジャイロ」を押すと、端末の向きに合わせて星空・地球・月面が動きます。
5. 良い構図が見つかったら、「💾 画面保存」(写真)か「⏺ 録画」(動画)で保存します。

## 主な機能

| 機能 | 内容 |
|---|---|
| タップで対象を指定・追跡 | タップした点から、ものの色の特徴を学習して追跡します。ものを最前面、それ以外を背景として描画します。 |
| ジャイロ連動 | 端末の3軸の姿勢(傾きを含む)を使い、星・地球・太陽・月面を実際の向きで描画します。 |
| 月面 | クレーター・岩・砂のでこぼこを持つ起伏データから生成します。低い太陽光による陰影と、くっきりした影が出ます。 |
| 距離に連動する見え方 | ものの映る大きさと位置の変化から端末の動きを推定し、月面が近づいたり遠ざかったりして見えます。 |
| 星空・地球 | 星空と天の川、満ち欠けのある地球を、太陽の位置と連動して描画します。 |
| ものとの合成 | ものが地面に落とす影、太陽側の明るさ、地球照(青い反射光)を加えます。 |
| 保存 | 描画した画面を PNG で保存、または動画で録画します。 |

## 操作

- **ドラッグ**: 視点を動かします(ジャイロ中は方位をずらします)。
- **ピンチ(2本指)**: 月面からの高度を変えます。広げると近づき、縮めると遠ざかります。
- **プリセット**: ⬇地表 / ➖水平線 / 🌍地球を見る / ✨星空
- **⌖ 正面リセット**: ジャイロ中に、いま向いている方向を正面にします。
- **✖ 対象解除**: 追跡中のものを解除します。ものの別の部分をタップすると、その部分も対象に追加されます。

## 設定(🎛)

- **背景除去**: タップ指定(標準)のほか、緑・青・黒・白のクロマキー、タップした色の指定、背景差分のモードがあります。
- **宇宙の見た目**: 太陽の方位・高度、地形の影、ものの影の長さ、ものの陰影、地球照、地球の大きさ、星の量、被写体のコントラスト。
- **月面との距離感**: カメラ高度、距離連動の強さ、移動の倍率、撮影距離。
- **カメラ・視点**: 画角、背景の画質、前面/背面カメラの切り替え。

動きが重いときは、「背景の画質」を下げてください。

## 動作環境

- **HTTPS で開く必要があります。** カメラとジャイロは、HTTPS でないと許可されません(`http://` の社内サーバーなどでは動きません)。
- iOS 14.5 以降の Safari を想定しています。Chrome・Edge などでも動く見込みですが、確認していません。
- LINE・Instagram などのアプリ内ブラウザでは、カメラが許可されないことがあります。Safari で開いてください。
- iOS では、初回に「モーションセンサー」の許可が必要です。

## 制限事項

- 位置の推定は、ものの映る大きさと位置の変化を使っています。ARKit のような正確な位置追跡ではありません。
- ものと背景の色が近いと、うまく切り出せません。ものが画面の端にかからないようにしてください。
- 素早く動かすと、追跡が外れることがあります。外れたときは、もう一度ものをタップしてください。
- iOS のジャイロの方位は、相対値です。実際の北とは一致しません。
- 複数の端末は、互いに通信しません。設定や映像は、端末ごとに独立しています。

## 開発

- ビルドは不要です。`index.html` 1つで完結し、外部ライブラリも使っていません。
- 月面・地球・星の画像は、起動時にコードで生成します。
- ローカルで試すときは、HTTPS で配信する必要があります(カメラ許可のため)。
- GitHub Pages で公開しています。`main` ブランチのルートが公開されます。`index.html` を更新してプッシュすると、1〜2分で反映されます。

## 技術メモ

- 描画は Canvas 2D です。月面は、レイとの平面の交差で、1ピクセルずつ計算しています。
- 月面の起伏データ(高さと反射率)は、ミップマップにしてあります。拡大・縮小しても細部が出続けるように、16倍ごとの階層で自己相似に重ねます。
- 影は、起伏データの地平線テストで計算します(太陽が動くと再計算)。
- ものの追跡は、色のヒストグラムによる前景/背景の分類と、連結成分の選択で行います。
